Remember to configure your Git account with your name and email address after to fork the repositories. This is important because Git uses this information to identify the author of the commits you create. You can configure your Git account using the following commands:

git config --local user.name "<Your Name>"
git config --local user.email "<your email>"

2. Platform

The following platform is required for running the exercises in this tutorial.

  • Red Hat OpenShift Container Platform 4.18 with the following Operators:

    • Red Hat OpenShift Service Mesh 2.6.7 Operator.

    • Kiali Operator 2.4.4 provided by Red Hat.

The files used to deploy the operators are located in the following GitHub repository:

git clone https://github.com/nveces/ocp-servicemesh-labs-2025.git

or if you prefer to use SSH, git clone git@github.com:nveces/ocp-servicemesh-labs-2025.git.

Finally, navigate to the new folder created in your system after repository download:

cd ocp-servicemesh-labs-2025/lab-00

To deploy the Red Hat OpenShift Service Mesh 2.6.7 Operator, you can use the following command:

oc apply -f 10-ns-istio-system.yaml
oc apply -f 11-ns-openshift-distributed-tracing.yaml
oc apply -f 20-operatorgroup-openshift-distributed-tracing.yml
oc apply -f 31-sub-kiali.yaml
oc apply -f 32-sub-openshift-distributed-tracing.yaml
oc apply -f 42-servicemesh-controlplane-jaeger.yaml
oc apply -f 50-servicemesh-memberroll.yaml
These steps have already been completed by the instructor team.

3. OpenShift Cheat Sheet

To view its API documentation without accessing the internet, examples:

oc api-resources
oc api-resources | grep deployment
oc api-resources | head -n 5
oc api-resources --verbs=list --namespaced -o name

More examples:

oc api-resources | grep "maistra"
oc api-resources --api-group="authentication.maistra.io" --sort-by=name -o wide
oc api-resources --api-group="federation.maistra.io"     --sort-by=name -o wide
oc api-resources --api-group="maistra.io"                --sort-by=name -o wide
oc api-resources --api-group="rbac.maistra.io"           --sort-by=name -o wide
oc api-resources | grep -i "istio"
oc api-resources --api-group="networking.istio.io"  --sort-by=name -o wide

To view your API versions, type:

oc api-versions
oc api-versions | grep "maistra"

Explore the APIs. To view the contents of an API in detail, use:

oc explain
