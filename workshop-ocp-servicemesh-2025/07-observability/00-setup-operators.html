Lab 1 - Install Tempo Operator

Naturally, we could install operators using the OpenShift Web Console, but for this tutorial, we will use the CLI.

Navigate to the project folder in your system after repository download for completing all tasks included in this tutorial:

cd ocp-servicemesh-labs-2025/lab-00/tempo

Create the openshift-tempo-operator namespace:

oc apply -f 10-ns-tempo-operator.yaml

Create an Operator group:

oc apply -f 20-operatorgroup-tempo.yaml

Create the subscription:

oc apply -f 30-sub-tempo.yaml
How to know the current version of an operator.

Before to create subscrption, if you want to know the specific channel name, currentCSV, and other information about this operator, run the following command:

oc get packagemanifest tempo-product -o yaml

We highlight the lines:

.../...
status:
  catalogSource: redhat-operators
  catalogSourceDisplayName: Red Hat Operators
  catalogSourceNamespace: openshift-marketplace
  catalogSourcePublisher: Red Hat
  channels:
  - currentCSV: tempo-operator.v0.15.4-1
.../...

Check the Operator status by running the following command:

oc get csv -n openshift-tempo-operator
oc get csv -n openshift-tempo-operator | grep tempo
tempo-operator.v0.15.4-1     Tempo Operator        0.15.4-1   tempo-operator.v0.15.3-1       Succeeded

Lab 2 - Install Red Hat build of OpenTelemetry Operator

Naturally, we could install operators using the OpenShift Web Console, but for this tutorial, we will use the CLI.

Change directory to the lab-00/03-coo folder:

cd ocp-servicemesh-labs-2025/lab-00/03-coo

Create the openshift-opentelemetry-operator namespace:

oc apply -f 12-ns-opentelemetry-operator.yaml

Create an Operator group:

oc apply -f 21-operatorgroup-opentelemetry-operator.yaml

Create the subscritpion:

oc apply -f 31-sub-opentelemetry.yaml

Check the Operator status by running the following command:

oc get csv -n openshift-opentelemetry-operator
oc get csv -n openshift-opentelemetry-operator | grep "opentelemetry"
opentelemetry-operator.v0.119.0-2   Red Hat build of OpenTelemetry      0.119.0-2   opentelemetry-operator.v0.119.0-1      Succeeded

Lab 3 - Install Cluster Observability Operator

Naturally, we could install operators using the OpenShift Web Console, but for this tutorial, we will use the CLI.

Change directory to the lab-00/03-coo folder:

cd ocp-servicemesh-labs-2025/lab-00/03-coo

Create the subscription:

oc apply -f 20-sub-cluster-observability-operator.yaml

Check the Operator status by running the following command:

oc get csv -n openshift-operators
oc get csv -n openshift-operators | grep "cluster-observability"
cluster-observability-operator.v1.1.1   Cluster Observability Operator       1.1.1
cluster-observability-operator.v1.1.0     Succeeded

We install the distributedTracing plugin for the Cluster Observability Operator:

oc apply -f 30-uiplugin-distributedTracing.yaml
