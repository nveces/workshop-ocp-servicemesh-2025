== Deploy _Jump App_ Microservices

_Jump App_ is a microservice-based application created to emulate an enterprise application complex architecture with multi environments. This app allows users to configure a set of jumps between components and generate a continuous traffic flow defining the number of retries and their span of time.

First of all, it is required to deploy Jump App application in Openshift in order to have the demo application environment ready. The following steps in this section helps you to deploy _Jump App_.


IMPORTANT: If you realized the previous lab, you should have already deployed the _Jump App_ application. In this case, you can skip this stop and go to the next one xref:04-troubleshooting/index.adoc#resetapp[Reset Jump App].


[#resetapp]
=== Reset _Jump App_ Application

If you want to reset the _Jump App_ application, you can do it by following the next steps:

[.console-input]
[source,bash,subs="+macros,+attributes"]
----
oc delete all,virtualservices,destinationrules,gateways,ServiceMeshMember,EnvoyFilter,ServiceEntry --all -n <usernamespace>
oc delete route back-golang-<usernamespace> -n istio-system
oc delete route front-javascript-<usernamespace> -n istio-system
oc delete secret <usernamespace>-credential  -n istio-system
----

Navigate to the new folder created in your system for completing all tasks included in this tutorial:

[.console-input]
[source,bash,subs="+macros,+attributes"]
----
cd ocp-servicemesh-labs-2025/lab-04
----

[#jumpappobjects]
=== Create _Jump App_ Objects in Openshift

First of all, it is required to modify _params.env_ file to include the parameters provided by the Instructor:

[.lines_7]
[.console-input]
[source,bash,subs="+macros,+attributes"]
----
vi params.env
----

.params file content
====
USER_NAMESPACE=user01-sm +
OCP_APPS_DOMAIN={ocp_apps_domain}
====

Once the params file is saved, you are able to process with _Jump App_ deployment phase:

[.lines_7]
[.console-input]
[source,bash,subs="+macros,+attributes"]
----
oc project $USER_NAMESPACE
oc process -f ./02-jump-app-deploy/jump-app-template.yml --param-file=./params.env --ignore-unknown-parameters | oc apply -f -
----
