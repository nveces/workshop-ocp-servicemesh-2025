== Introduction

*{rhossm_l}*, which is based on the open source https://istio.io/[Istio project,window=_blank], provides an easy way to create a network of deployed services that provides:

* Discovery,
* Load balancing,
* Service-to-service authentication,
* failure recovery,
* Metrics,
* and Monitoring

*{rhossm_l}* also provides more complex operational functions including:

* A/B testing
* Canary releases
* Access control
* End-to-end authentication
