== Introduction

Service Mesh, which is based on the open source https://istio.io/[Istio project,window=_blank], provides an easy way to create a network of deployed services that provides:

* discovery,
* load balancing,
* service-to-service authentication,
* failure recovery,
* metrics,
* and monitoring

The general idea of _Red Hat Service Mesh: Envoy & Istio Control Plane_ tutorial is to get a deep understanding of the following points:

- Service Mesh Communication Flows
- Istio-Envoy Objects Relationship
- Envoy Proxy
- Istio Control Plane Objects
- Istio Global Services
