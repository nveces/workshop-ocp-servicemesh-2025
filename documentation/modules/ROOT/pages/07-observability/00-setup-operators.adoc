Change directory to the `lab-00/01-opentelemetry` folder:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
cd ocp-servicemesh-labs-2025/lab-00/01-opentelemetry
----


Create the `openshift-opentelemetry-operator` namespace:


[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc apply -f 10-ns-opentelemetry-operator.yaml
----

Create the operator group:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc apply -f 20-operatorgroup-opentelemetry-operator.yaml
----

Create the subscription:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc apply -f 30-sub-opentelemetry.yaml
----


Check the Operator status by running the following command:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc get csv -n openshift-opentelemetry-operator
----

[.lines_space]
[source,bash, subs="+macros,+attributes"]
----
oc get csv -n openshift-opentelemetry-operator | grep "opentelemetry"
opentelemetry-operator.v0.119.0-2   Red Hat build of OpenTelemetry      0.119.0-2   opentelemetry-operator.v0.119.0-1      Succeeded
----


= Lab 2 - Install OpenTelemetry Collector


Change directory to the `lab-00/02-otel` folder:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
cd ocp-servicemesh-labs-2025/lab-00/02-otel
----


Create the `otel` namespace:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc apply -f 10-ns-otel.yaml
----


Create the `15-sa-otel-collector.yaml` serviceaccount:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc apply -f 15-sa-otel-collector.yaml
----

Create the `otel` OpenTelemetryCollector:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc apply -f 20-opentelemetrycollector-otel.yaml
----

Create the *ClusterRoles* and *ClusterRoleBindings* for the `otel-collector` serviceaccount:

[.lines_space]
[.console-input]

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc apply -f 30-cr-openshift-tracing-otel-collector.yaml
oc apply -f 31-cr-tempostack-traces-writer-dev.yaml
oc apply -f 32-cr-tempostack-traces-writer-prod.yaml
oc apply -f 40-crb-openshift-tracing-otel-collector.yaml
oc apply -f 41-crb-tempostack-traces-writer-dev.yaml
oc apply -f 42-crb-tempostack-traces-writer-prod.yaml
----
