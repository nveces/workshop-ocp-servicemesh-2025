== Introduction

include::./../../partials/04-troubleshooting/jaeger_deprecated.adoc[]

NOTE: The *Red Hat OpenShift distributed tracing platform (Jaeger)* is a deprecated feature. +
Deprecated functionality is still included in OpenShift Container Platform and continues to be supported; however, it will be removed in a future release of this product and is not recommended for new deployments.

NOTE: Users must migrate to the *Tempo Operator* and the Red Hat build of OpenTelemetry for distributed tracing collection and storage.


The *Tempo operator* supports for storing Tempo data:

* OpenShift Data Foundation,
* AWS S3,
* Azure,
* GCS
* and Minio.
