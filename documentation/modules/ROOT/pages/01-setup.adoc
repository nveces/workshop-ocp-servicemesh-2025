[source,bash]
----
$ oc version

Kustomize Version: v5.4.2
Server Version: 4.18.7
Kubernetes Version: v1.31.6
----

[source,bash]
----
$ git -v
git version 2.49.0
----


[IMPORTANT]
====
*Remember* to configure your Git account with your name and email address after to fork the repositories. This is important because Git uses this information to identify the author of the commits you create. You can configure your Git account using the following commands:

[.lines_space]
[.console-input]
[source,bash]
----
git config --local user.name "<Your Name>"
git config --local user.email "<your email>"
----

====



== Platform

The following platform is required for running the exercises in this tutorial. +

* *{rhocp}* with the following Operators:
** *{rhossm} Operator*.
** *{kiali_op_l}*.


The files used to deploy the operators are located in the following GitHub repository:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
git clone https://github.com/nveces/ocp-servicemesh-labs-2025.git
----

or if you prefer to use *SSH*, `git clone git@github.com:nveces/ocp-servicemesh-labs-2025.git`.


Finally, navigate to the new folder created in your system after repository download:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
cd ocp-servicemesh-labs-2025/lab-00
----

To deploy the *{rhossm} Operator*, you can use the following command:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc apply -f 10-ns-istio-system.yaml
oc apply -f 20-sub-servicemesh.yaml
oc apply -f 21-sub-kiali.yaml
oc apply -f 30-servicemesh-controlplane.yaml
----

NOTE: These steps have already been completed by the instructor team.
