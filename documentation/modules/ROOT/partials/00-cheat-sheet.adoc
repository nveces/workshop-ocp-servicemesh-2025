

To view its API documentation without accessing the internet, examples:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc api-resources
oc api-resources | grep deployment
oc api-resources | head -n 5
oc api-resources --verbs=list --namespaced -o name
----


More examples:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc api-resources | grep "maistra"
oc api-resources --api-group="authentication.maistra.io" --sort-by=name -o wide
oc api-resources --api-group="federation.maistra.io"     --sort-by=name -o wide
oc api-resources --api-group="maistra.io"                --sort-by=name -o wide
oc api-resources --api-group="rbac.maistra.io"           --sort-by=name -o wide
----

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc api-resources | grep -i "istio"
oc api-resources --api-group="networking.istio.io"  --sort-by=name -o wide
----


To view your API versions, type:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc api-versions
oc api-versions | grep "maistra"
----


*Explore the APIs*. To view the contents of an API in detail, use:

[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc explain
----

.Explore the *maistra* API resources.
[.lines_space]
[.console-input]
[source,bash, subs="+macros,+attributes"]
----
oc explain --api-version="authentication.maistra.io/v1"  servicemeshpolicies.spec
oc explain --api-version="federation.maistra.io/v1"      exportedservicesets.spec
oc explain --api-version="federation.maistra.io/v1"      importedservicesets.spec
oc explain --api-version="federation.maistra.io/v1"      servicemeshpeers.spec
oc explain --api-version="maistra.io/v2"                 servicemeshcontrolplanes.spec
oc explain --api-version="maistra.io/v2"                 servicemeshcontrolplanes.spec.gateways
oc explain --api-version="maistra.io/v1"                 servicemeshmemberrolls.spec
oc explain --api-version="maistra.io/v1"                 servicemeshmembers.spec
oc explain --api-version="rbac.maistra.io/v1"            servicemeshrbacconfigs.spec
----
